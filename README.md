# 📘 Projeto Java - Gerenciador de Turma de Alunos

Este projeto Java foi desenvolvido para armazenar e manipular os dados de uma turma da disciplina **Linguagem de Programação II**.

## 📌 Funcionalidades

- Cadastro de alunos com os seguintes dados:
  - Matrícula (única)
  - Nome
  - Curso
  - Notas e pesos de 4 provas

- Operações disponíveis:
  - ✅ Incluir aluno na turma (com verificação de matrícula duplicada)
  - ✏️ Alterar os dados de um aluno
  - 🔍 Consultar aluno por nome (primeiro ou todos)
  - 🔍 Consultar aluno por matrícula
  - ❌ Excluir aluno por nome
  - 📃 Imprimir alunos por ordem de inserção
  - 🔤 Imprimir alunos ordenados por nome
  - ✔️ Validar matrícula única antes de inserção/alteração
